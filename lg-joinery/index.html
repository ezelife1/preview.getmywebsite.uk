PLANNING THE DETAILS

A few useful starting points.

What should I prepare for my project?

Photographs, rough dimensions and a short description of how you want to use the space are a useful starting point.

Can I combine several types of work?

Describe each part of the project, such as decking with fencing or a staircase with wall panelling, so the overall scope is clear.

Which finishes should I consider?

Think about existing colours, flooring, furniture and how the space is used. The project gallery offers examples of timber, painted and composite finishes.
