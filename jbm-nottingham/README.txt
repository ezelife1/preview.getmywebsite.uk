FINAL DOMAIN REQUIRED BEFORE LIVE SHARING
No domain has been supplied for JBM. No invented domain or another client's address is included.
Run the included configure-domain.py with the actual HTTPS website address before uploading; it writes absolute OG/Twitter image URLs, canonical/og:url tags, schema URLs, sitemap.xml and the robots sitemap reference.
Example command (replace example.com with the actual address):
python3 configure-domain.py https://example.com
Alternatively send the final domain back for a configured ZIP.

FACEBOOK CRAWLING
robots.txt allows all crawlers and explicitly allows facebookexternalhit and Facebot. There are no bot blocks, authentication checks, noindex tags or image restrictions in these files. Social metadata is in static HTML; it does not require JavaScript.
