CALLARD CONSTRUCTION — WEBSITE

To view locally: extract the entire ZIP, then open index.html in your browser.
Keep the assets folder alongside the HTML files. No server or build step is required
for the pages or project videos. Contact links require the relevant phone,
email or WhatsApp app/service.

The website is a private review build marked noindex. The preview hostname in
the metadata is a staging convention; no live URL was assigned or tested.
Before public launch, run this in the extracted folder:
  python3 configure-launch.py https://your-confirmed-website-address
Include any repository subpath. Upload the extracted website contents, then
check the public pages, sitemap and social image and refresh the platform scrape.
Confirm the business mobile receives WhatsApp messages before launch.

The quote form opens a WhatsApp draft with the supplied details. It does not
send automatically. Phone and email links go directly to the business.
