Open index.html to view the website. To host it, upload the HTML,
style.css, script.js, assets folder and robots.txt together.

Before deployment, run this from the extracted folder:
  python3 configure-domain.py https://YOUR-PUBLIC-DOMAIN
Use the full HTTPS address, including a subdirectory if applicable.
This updates the page canonical URLs, social metadata and structured
data, and creates sitemap.xml. Upload the generated sitemap as well.
